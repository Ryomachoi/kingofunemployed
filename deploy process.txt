이 프로젝트는 Next.js 15(App Router), Supabase, OpenAI를 사용합니다 . 현재 로컬 개발 서버는 실행 중이며 http://localhost:3000 에서 확인 가능합니다.

권장 경로

- Vercel 배포 + 커스텀 도메인 연결 + Supabase 연동
- 장점: 설치/서버관리 없이 쉽게 운영, SSL 자동, 무료로 시작 가능
준비물

- Vercel 계정(무료)
- GitHub 계정(소스 저장을 위해)
- 도메인(Cloudflare/Gabia 등에서 구매)
- Supabase 프로젝트(URL/anon key, service role key)
- OpenAI 계정 및 API 키, Responses Prompt ID
전체 단계

- 1. GitHub에 코드 올리기
  - 무엇: 현재 폴더를 GitHub 저장소로 push
  - 어디서: GitHub Desktop 또는 Git Bash에서 진행
  - 방법 요약: GitHub Desktop → “Add local repository” → “Publish to GitHub”
- 2. Vercel에서 프로젝트 가져오기(Import)
  - 무엇: GitHub 저장소를 Vercel 프로젝트로 만들기
  - 어디서: vercel.com → “New Project” → 저장소 선택 → Deploy
- 3. 환경변수 설정
  - 무엇: 운영에 필요한 키/URL을 Vercel 프로젝트 Settings → Environment Variables에 추가
  - 어디서: Vercel 프로젝트 → Settings → Environment Variables
  - 목록
    - NEXT_PUBLIC_SUPABASE_URL
    - NEXT_PUBLIC_SUPABASE_ANON_KEY
    - SUPABASE_SERVICE_ROLE_KEY(서버 전용)
    - OPENAI_API_KEY
    - OPENAI_PROMPT_ID
    - OPENAI_PROMPT_VERSION(선택, 기본 8)
    - NEXT_PUBLIC_SITE_URL(초기엔 배포된 vercel.app 주소, 도메인 연결 후 도메인으로 교체)
    - NAVER_CLIENT_SECRET(비공개, 콜백 처리에서 사용)
  - 참고: 코드에서의 사용 위치
    - Supabase 서버/브라우저 클라이언트: server.ts , client.ts
    - OpenAI 호출: interview/analyze API
    - Naver OAuth: naver route , naver callback
- 4. Supabase 준비(새 프로젝트이거나 기존 프로젝트 연결)
  - 무엇: 데이터베이스 테이블/정책 생성
  - 어디서: Supabase 대시보드 → SQL Editor
  - 실행: README의 SQL 스크립트를 순서대로 적용 README.md
  - 키 확인: Project Settings → API에서 URL/keys 복사해 Vercel 환경변수에 입력
- 5. OpenAI 준비
  - 무엇: Responses Prompt 생성 및 ID 확인
  - 어디서: OpenAI 콘솔 → Responses → Prompt
  - 설정: OPENAI_API_KEY, OPENAI_PROMPT_ID(+ VERSION) 환경변수 입력
- 6. OAuth 콜백/도메인 반영
  - 무엇: 네이버 OAuth 콜백을 운영 도메인으로 교체
  - 어디서: 네이버 개발자센터 → 앱 설정 → Callback URL
  - 값: https://도메인/api/auth/naver/callback
  - 코드 경로 참고: naver route , naver callback
- 7. 도메인 연결
  - 무엇: 도메인 구매 후 Vercel에 연결
  - 어디서: Vercel 프로젝트 → Settings → Domains
  - 방법: 도메인 추가 후 Vercel가 안내하는 DNS(CNAME 또는 NS) 레코드를 등록기관에서 설정 → 전파 대기 → SSL 자동 발급
- 8. 최종 확인
  - 무엇: 배포 사이트에서 주요 기능 점검
  - 체크:
    - 로그인/마이페이지 접근
    - 면접 분석(OpenAI) 호출
    - 게시판 보기/글 상세 보기
    - 공유/공개 토글 API 응답

지금 바로 같이 시작하는 순서(당장 수행할 액션)

- 1. GitHub에 올리기
  - GitHub Desktop 열기 → Add local repository → Publish to GitHub
  - 완료되면 저장소 URL을 알려주세요
- 2. Vercel 프로젝트 만들기
  - vercel.com → New Project → 방금 만든 GitHub 저장소 선택 → Import
  - Framework 자동 감지(Next.js)
- 3. Vercel 환경변수 입력
  - Settings → Environment Variables
  - 아래 키를 추가(값은 당신의 Supabase/OpenAI 콘솔에서 복사)
    - NEXT_PUBLIC_SUPABASE_URL
    - NEXT_PUBLIC_SUPABASE_ANON_KEY
    - SUPABASE_SERVICE_ROLE_KEY
    - OPENAI_API_KEY
    - OPENAI_PROMPT_ID
    - OPENAI_PROMPT_VERSION(필요시)
    - NEXT_PUBLIC_SITE_URL(초기엔 Vercel 제공 도메인)
    - NAVER_CLIENT_SECRET(비공개)
- 4. Supabase SQL 적용
  - Supabase → SQL Editor → README 스크립트 순서대로 실행
- 5. OpenAI Prompt 생성
  - OpenAI 콘솔 → Prompt 생성 → ID/Version 확인 후 Vercel에 입력
- 6. 도메인 연결
  - Vercel → Settings → Domains → 도메인 추가
  - 등록기관 DNS에서 CNAME/NS를 Vercel 안내대로 설정
- 7. 네이버 콜백 업데이트
  - 네이버 개발자센터 → Callback URL을 운영 도메인으로 설정
운영 팁

- 초기 배포는 타입/ESLint 오류를 무시하고 진행하도록 설정되어 있어 빌드가 성공합니다(나중에 점진적으로 타입/린트 오류를 해결하면 품질 향상). 해당 설정 파일: next.config.js
- NAVER_CLIENT_SECRET은 비공개로 유지하고, client_id만 공개 변수로 유지
- Supabase Service Role Key는 서버에서만 사용(브라우저에 노출 금지)
